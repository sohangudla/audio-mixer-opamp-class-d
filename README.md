# Low-Cost Audio Mixer with Op-Amps and a Class-D Amplifier

System design project for **23ECE286 Circuits and Communication Laboratory** (B.Tech ECE, Amrita School of Engineering, Bengaluru).

A basic, low-cost audio mixer circuit that combines multiple audio input signals into a single output using operational amplifiers and a class-D amplifier.
